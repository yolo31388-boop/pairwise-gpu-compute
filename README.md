# 游戏内GPU计算与通用计算系统

## 项目描述

游戏内GPU计算与通用计算系统的bug修复项目。核心模块 `gpu/compute.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 计算调度完全没做所有计算都在CPU上
- 通用计算完全没做只能用图形管线做计算
- 并行计算完全没做不能并行处理数据
- 计算着色器完全没做不能在GPU上运行程序
- GPU内存管理完全没做不能管理GPU内存

## 运行测试

```bash
python -m pytest tests/test_gpu_compute.py -q
```

修复目标：所有 16 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
